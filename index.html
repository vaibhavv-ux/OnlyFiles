Questions
Questions people actually ask

      

        

          Do my files ever get uploaded anywhere?+
          
No. Every tool runs with your browser's own decoding, canvas, crypto and recording APIs. There's no server call in the processing path — you can disconnect your Wi-Fi after the page loads and every tool still works.

        

        

          What's actually included in the free version vs. Pro?+
          
Image compress & convert, PDF compress, JPG to PDF, video compress, decrypting a file someone sends you, and photo filters & effects are free forever, no account needed. The other 13 tools — batch processing, watermarking, the privacy scrubber, favicon kit, PDF merge and page editing, video trim & frame grabber, encryption, QR codes, the bulk renamer, blur & pixelate, and the image upscaler — unlock with one $4.99 lifetime payment.

        

        

          Is $4.99 really one-time, not monthly?+
          
Yes. One charge, no recurring billing, no card kept on file for a renewal. If a separate paid tier is ever added later, anything you already unlocked stays unlocked.

        

        

          How does the metadata scrubber actually work?+
          
Photos from phones and cameras often embed EXIF data — GPS coordinates, camera model, timestamp, sometimes even the software used to edit them. The Privacy Scrubber reads that block directly from the file's bytes, shows you exactly what's in it, then removes it either losslessly (cutting just the metadata segment, so image quality is untouched) or by re-encoding the pixels fresh. All of this happens locally; the file is never sent anywhere to be inspected.

        

        

          Is the encryption actually secure?+
          
The Security Vault uses AES-256-GCM with a key derived from your password via PBKDF2 (250,000 iterations, SHA-256) — all through your browser's native Web Crypto API, the same primitives used by password managers. Your password and the original file never leave your device, and OnlyFiles has no way to recover a lost password.

        

        

          Do I need to create an account?+
          
No login is required for any tool. After purchase, this browser remembers that you've unlocked Pro so you can come back anytime. A full cross-device account system (with sign-in) is planned for a future update.

        

        

          Does it work on my phone?+
          
Yes — it's a website, not an app, so it runs in any modern mobile or desktop browser without an install. Some heavier tools (video processing) are faster on desktop.
